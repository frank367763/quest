# Quest

Небольшая викторина для Android на Java. Вопросы с несколькими вариантами ответа, подсказки на отдельном экране и раскладка для альбомного режима.

Открой проект в Android Studio, дождись синхронизации Gradle и запусти модуль app. Для сборки нужен Android SDK 37, для запуска — Android 7.0 или новее.
